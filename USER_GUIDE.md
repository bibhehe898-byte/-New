# Kataxone — руководство пользователя

Добро пожаловать! Этот документ — пошаговая инструкция, как запустить Kataxone и пройтись по всем функциям. Она рассчитана на первое знакомство с продуктом: от запуска серверов до демонстрации «живой» синхронизации между 3D-туром и редактором.

> **Коротко о продукте.** Kataxone — это интерактивная 3D-карта потока создания ценности (КПСЦ). Вы осматриваете производственный цех в панораме, редактируете этапы процесса на графе и видите экономический эффект изменений на дашборде.

---

## 1. Запуск проекта

Проект состоит из двух частей, которые нужно запустить **одновременно** в двух разных терминалах: бэкенд (Python/FastAPI) и фронтенд (React/Vite).

### 1.1. Бэкенд (Python)

Выполните из **корня репозитория**:

```bash
pip install -r backend/requirements.txt
uvicorn backend.main:app --reload
```

После запуска API доступен по адресу **http://127.0.0.1:8000**.
Интерактивная документация API (Swagger) — **http://127.0.0.1:8000/docs**.

### 1.2. Фронтенд (React)

В отдельном терминале, также из корня репозитория:

```bash
npm install
npm run dev
```

Приложение откроется по адресу, который выведет Vite (по умолчанию **http://localhost:5173**).

> Проверьте, что **оба** сервера запущены. Фронтенд обращается к бэкенду по `http://127.0.0.1:8000` — без него вход и сохранение графов не заработают.

## 2. Вход в систему

Формы регистрации в интерфейсе пока нет, поэтому первого пользователя создаём через Swagger.

### 2.1. Регистрация первого пользователя

1. Откройте **http://127.0.0.1:8000/docs**.
2. Найдите метод **`POST /api/register`** и нажмите **Try it out**.
3. В теле запроса укажите логин и пароль, например:

   ```json
   {
     "username": "demo",
     "password": "demo"
   }
   ```

4. Нажмите **Execute**. В ответе вернётся `access_token` — значит, пользователь создан.

> Альтернативно это же можно сделать через терминал:
> ```bash
> curl -X POST http://127.0.0.1:8000/api/register \
>   -H "Content-Type: application/json" \
>   -d '{"username": "demo", "password": "demo"}'
> ```

### 2.2. Вход в приложение

1. Откройте **http://localhost:5173** — появится страница входа.
2. Введите логин и пароль созданного пользователя.
3. **Обязательно** отметьте галочку **«Я согласен на обработку персональных данных (ФЗ-152)»** — без неё вход заблокирован.
4. Нажмите **«Войти»**.

После входа вы попадёте в 3D-тур. Выйти можно кнопкой **«Выйти»** в правой части шапки.

## 3. 3D-тур

На главной странице вы находитесь внутри панорамы производственного цеха.

- **Осмотреться** — перетаскивайте панораму мышью.
- **Масштаб** — прокручивайте колесо мыши.
- **Точки интереса (POI)** — это этапы потока. Они видны:
  - пульсирующими метками прямо в панораме;
  - списком на панели слева.
- **Клик по POI** — камера плавно поворачивается к выбранному этапу, а в карточке появляется его название, загрузка и время цикла.
- **Переключение цехов** — кнопка **«Перейти в Цех 2» / «Вернуться в Цех 1»** переключает панорамы.

Обратите внимание: метки в панораме «пульсируют» как радар, а фон карточки точки интереса слегка «течёт» — так визуально передаётся движение потока.

## 4. Редактор КПСЦ

Откройте раздел **«Редактор КПСЦ»** в верхнем меню. Здесь процесс показан как граф этапов.

- **«До» / «После»** — переключение между текущим и целевым состоянием потока.
- **«Добавить этап»** — добавляет новый узел в конец цепочки.
- **Создание связей** — потяните от точки-разъёма на краю узла к другому узлу; между ними появится стрелка.
- **Редактирование параметров** — кликните по узлу, чтобы открыть окно. Здесь можно поменять:
  - название;
  - время цикла (мин);
  - загрузку (%);
  - стоимость (₽).
  Нажмите **«Сохранить»**, чтобы применить изменения.
- **Удаление** — выделите узел или связь и нажмите **Delete** или **Backspace**.
- **«Сбросить»** — возвращает текущую версию потока к исходному виду.
- **«Сохранить на сервер»** — сохраняет текущую версию («До» или «После») в базу данных.

При входе в редактор граф **автоматически подгружается с сервера** (если он ещё не сохранён — используются данные по умолчанию). На связях виден анимированный «бегущий ток» — он показывает направление потока.

---

## 5. Дашборд «До/После»

Откройте раздел **«Дашборд До/После»** в верхнем меню.

- **Вверху** — главный показатель сокращения времени протекания и расчётная **экономия в рублях/год**.
- **Ключевые показатели** — сравнение «До» и «После» по этапам, времени цикла и доле добавленной ценности.
- **Быстрая симуляция** — для каждого узкого места (загрузка > 90%) есть свой ползунок. Передвиньте его — время цикла меняется, и все метрики вместе с экономией **пересчитываются на лету**.
- **«Скачать план улучшений»** — выгружает текстовый файл со списком задач по оптимизации узких мест.

Попробуйте уменьшить время цикла узкого места и посмотрите, как растёт экономический эффект.

## 6. Магия синхронизации: 3D-тур ↔ Редактор

3D-тур и Редактор работают **на одних и тех же данных** (единое состояние приложения). Поэтому одни и те же этапы, их названия и параметры видны и в панораме, и на графе. Связь двусторонняя.

### Из редактора в 3D-тур

1. Откройте **Редактор КПСЦ** и кликните по любому узлу.
2. В окне редактирования нажмите **«Показать в 3D»**.
3. Приложение переключится в 3D-тур, и камера **плавно наведётся на выбранный этап** в панораме.

### Из 3D-тура в редактор

1. В 3D-туре кликните по **точке интереса** — в панораме или в списке слева.
2. Перейдите в **Редактор КПСЦ** через верхнее меню.
3. Граф **плавно отцентрируется** на этом этапе, а узел **подсветится**.

Как это работает: при клике 3D-тур сохраняет ID выбранного этапа в общее состояние, а редактор при открытии находит этот узел, наводит на него камеру графа и выделяет его. В обратную сторону то же самое делает кнопка **«Показать в 3D»**.
